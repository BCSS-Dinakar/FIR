# FIRAudit Frontend

This is the React.js frontend for the FIRAudit AI Legal Intelligence platform.

It is built to look extremely premium with highly responsive glassmorphic UI elements, glowing gradients, smooth micro-animations, and full Dark/Light mode support.

## Tech Stack
- React.js (Create React App)
- Tailwind CSS (for styling and animations)
- React Router DOM (for navigation)

## Available Scripts

In the project directory, you can run:

### `npm start`
Runs the app in development mode on `http://localhost:3000`.

### `npm run build`
Builds the app for production to the `build` folder.
